# Movie Catalog

A simple movie catalog application built with React and powered by The Movie Database (TMDB) API. The application allows users to browse popular movies, search for titles, and manage a personal favorites list stored locally in the browser.

## Disclaimer

This project was developed strictly for learning and practice purposes.

It is a proof of concept created while studying React fundamentals, including component architecture, state management, Context API, API integration, and local data persistence.

I am not the original creator of this application concept or design. This project is a personal recreation built as part of my learning journey, with the goal of understanding and applying modern React development practices.

## Features

* Browse popular movies from TMDB
* Search movies by title
* View movie posters and release years
* Add and remove favorite movies
* Persist favorites using Local Storage
* Responsive user interface

## Technologies Used

* React
* JavaScript (ES6+)
* CSS3
* TMDB API
* React Context API
* Local Storage

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/movie-catalog.git
```

Navigate to the project directory:

```bash
cd movie-catalog
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
